# Ads by Kanapiya — RU / EN

Статический сайт на основе предоставленного макета: русский по умолчанию, переключение на английский, 25 услуг с подробными страницами, архив из 14 кейсов, 28 клиентов, тарифы в USD / RUB / KZT и форма заявки в мессенджеры.

React, шрифты, стили и логотипы хранятся локально. npm-зависимости, API-ключи, база данных и сервер приложений не нужны.

## Локальный запуск

Нужен Node.js 20 или новее:

```sh
node scripts/serve.mjs
```

Откройте http://127.0.0.1:4173. Проверка: `node scripts/check.mjs`. Сборка: `node scripts/build.mjs`. Также доступны `npm run dev`, `npm run check`, `npm run build`.

## GitHub Pages

1. Загрузите содержимое проекта в репозиторий GitHub, включая `.github`.
2. Используйте ветку `main` или `master`; для другого имени измените `branches` в `.github/workflows/deploy.yml`.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Запустите **Actions → Deploy portfolio to GitHub Pages → Run workflow**, если файлы уже были загружены до настройки Pages.
5. Адрес опубликованного сайта появится в **Settings → Pages**.

Workflow проверяет и собирает сайт, затем публикует только `dist`. Пути относительные: поддерживаются и корневой домен, и `username.github.io/repository/`. Детальные страницы используют hash-маршруты, поэтому прямое открытие и обновление работают на GitHub Pages без серверных редиректов.

```text
index.html?lang=ru
services.html?lang=ru
services.html?lang=ru#/services/seo
cases.html?lang=en
cases.html?lang=en#/cases/python-reporting
clients.html?lang=ru
```

## Форма заявки

Контакты в `site/assets/config.js`: WhatsApp **+7 707 340 68 88**, Telegram **@muhamed_kanapiya**.

Посетитель выбирает услугу, вводит имя, контакт, необязательный адрес сайта и описание задачи. Под формой виден готовый текст. Кнопка открывает адрес владельца в выбранном мессенджере с заполненным черновиком; посетитель нажимает «Отправить» в самом мессенджере. Автоматическая отправка в оба канала не выполняется. Можно скопировать текст, если приложение не поддерживает предзаполнение.

Кнопки тарифов заранее выбирают услугу и включают тариф в сообщение. Поля сохраняются при переключении языка и валюты на странице, но не записываются в localStorage и не отправляются на сервер. В localStorage хранятся только язык и валюта. Контактные данные появляются в URL мессенджера только после нажатия соответствующей кнопки.

Форматы ссылок: [WhatsApp click to chat](https://faq.whatsapp.com/5913398998672934), [Telegram public username links](https://core.telegram.org/api/links#public-username-links).

## Стоимость

Базовые тарифы перенесены из макета: аудит $49, запуск $350, ведение $250/месяц + 10% рекламного бюджета. Для новых направлений указана оценка по запросу. Окончательный объём и стоимость согласуются до начала работы.

USD — базовая валюта. RUB и KZT пересчитываются по сохранённому официальному курсу НБК за **05.10.2026**: 1 USD = 447,73 KZT; 1 RUB = 5,35 KZT. Округление до целой единицы. Это ориентировочный пересчёт, дата и источник видны в блоке стоимости; автоматического обновления курса нет. Обновлять `exchange` в `config.js`.

Источник: https://nationalbank.kz/rss/get_rates.cfm?fdate=05.10.2026. Валюта меняет цены услуг, но не показатели кейсов.

## Кейсы и клиенты

Все 14 кейсов содержат **демонстрационные данные**: 6 из референса и 8 новых сценариев. Это явно указано в карточках, архиве и на каждой детальной странице. Они не приписаны реальным клиентам. При появлении подтверждённых результатов замените соответствующий текст и показатели. Вымышленные отзывы из референса не отображаются.

`site/assets/clients.js` содержит 28 компаний, предоставленных владельцем. На главной показываются 4 записи с `featured: true` и приглашение «Ваш проект»; полный список находится на `clients.html`. Лимит регулируется `featuredClientsLimit` в конфигурации.

18 логотипов сохранены с официальных сайтов. Источники — `site/assets/logos/SOURCES.json`; остальные компании представлены монограммами. VA Collision и LTC KZ не связаны с неоднозначными найденными сайтами. Для zanconsultant.kz оставлена монограмма: текущая главная использует другой бренд. Без URL карточка остаётся обычной карточкой. При ошибке загрузки логотипа автоматически появляется монограмма.

Логотипы принадлежат их правообладателям и используются для идентификации клиентов. Истории оказанных услуг или результаты сотрудничества для этих компаний не выдуманы.

## Где редактировать

- `site/index.html`, `services.html`, `cases.html`, `clients.html` — четыре точки входа.
- `site/assets/config.js` — имя, контакты, валюты, лимит клиентов на главной.
- `site/assets/clients.js` — список клиентов и логотипы.
- `site/assets/reference-app.js` — исходные 15 услуг, 6 сценариев, главный экран и процесс.
- `site/assets/catalog.js` — дополнительные 10 услуг, 8 сценариев и переводы нового интерфейса.
- `site/assets/extensions.js` — архивы, подробные страницы, цены и форма.
- `site/assets/portfolio.js` — язык, маршруты и клиентские карточки.
- `site/assets/translations.js` — русские переводы исходного макета.
- `site/assets/extensions.css` — стили новых компонентов и адаптивность.

Исходный визуальный референс: https://www.meta.ai/share/a/12a12a81-5250-41de-b03b-64bdcf4aad43. Компании с первоначального примерного скриншота не включены.
